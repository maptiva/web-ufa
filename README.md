# UFA · Una Forma Amable — Web

Peluquería canina en Paraná, Entre Ríos. Sitio de presentación (v1 estática).

## Stack

- **Astro 5** (estático, mobile-first)
- **Hosting:** Vercel (a configurar)
- **Contacto:** WhatsApp (sin backend en v1)

## Estructura

- `src/pages/` — páginas (home = `index.astro`)
- `src/components/` — componentes por sección (a crear)
- `src/layouts/` — layouts base (a crear)
- `public/` — estáticos (favicon, imágenes optimizadas WebP)
- `docs/` — wireframe y documentos de trabajo (no se publican)

## Comandos

```sh
npm install   # instalar dependencias
npm run dev   # desarrollo local
npm run build # build de producción
```
